# 🌍 NGO Website
This is a fully responsive and modern website developed for a Non-Governmental Organization (NGO). The website aims to raise awareness, promote campaigns, showcase success stories, and encourage donations or volunteering.

The project is built using standard web technologies such as HTML, CSS, and JavaScript, along with UI frameworks Tailwind CSS and Bootstrap to ensure clean design, responsiveness, and fast development. The design focuses on accessibility, usability, and clear calls to action to help the NGO reach its mission more effectively.

A fully responsive, modern, and user-friendly website designed for a Non-Governmental Organization (NGO). This project highlights the mission, campaigns, volunteer opportunities, and donation options of the NGO.

## 🚀 Features

- Responsive Design (Mobile-Friendly)
- Interactive UI with smooth transitions
- Donation and Volunteer Forms
- Campaign and Events Section
- Contact Page with Map Integration
- Testimonials/Success Stories Section

## 🛠️ Tools & Technologies

- **HTML5** – Structure and content
- **CSS3** – Styling
- **JavaScript** – Interactivity and dynamic content
- **Tailwind CSS** – Utility-first CSS framework for modern UI design
- **Bootstrap 5** – Responsive layout and UI components
- **Google Fonts** – Custom typography
- **Font Awesome** – Icons for UI elements
